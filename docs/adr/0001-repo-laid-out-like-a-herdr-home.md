# The repo is laid out like a Herdr home

Whistle's code lives in `mods/whistle/` and whistle-ui's in `mods/whistle-ui/`, with `keys.json`,
`RECIPE.md` and `preview.png` at the top, instead of at the repo root: Herdr's AGENTS.md
describes a shared mod as a folder laid out like a Herdr home, which is what herdr.dev lists and
what an agent copies into a person's home. Docs, tests, the keynav checker and the poster source
stay outside `mods/`, so a copy of a mod's folder is exactly that mod.
