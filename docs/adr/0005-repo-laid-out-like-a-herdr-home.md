# The repo is laid out like a Herdr home

The mod's code lives in `mods/whistle/`, with `keys.json`, `RECIPE.md` and `preview.png` at the
top, instead of at the repo root: Herdr's AGENTS.md describes a shared mod as a folder laid out
like a Herdr home, which is what herdr.dev lists and what an agent copies into a person's home.
Docs, tests and the poster source stay outside `mods/whistle/`, so a copy of that folder is
exactly the mod.
